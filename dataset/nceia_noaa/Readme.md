The dataset for weather required for New York City is obtained from National Centers of Environmental Information
URL: https://www.ncei.noaa.gov/

NCEI environmental data provides large area of spectrum of weather data from multiple weather stations deployed at different geographical locations.
It provides access to historical data for various studies continents which span accross multiple scientific disciplines.
Naming conventions, file formats and archive methods are defined for easy access of data available. 

NCEI develops software, APIs, visualization methods, and other services to enhance data access, discovery, and interoperability.

The data is covered under NESDIS/NCEI Open Data policy.

Relevant data for the duration of this project (November, 2023 till July, 2024) is mined from below archive 
* https://www.ncei.noaa.gov/data/global-hourly/archive/csv/2023.tar.gz
* https://www.ncei.noaa.gov/data/global-hourly/archive/csv/2024.tar.gz
